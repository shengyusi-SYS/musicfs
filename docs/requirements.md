# MusicFS 产品范围

MusicFS 将来源插件提供的音乐内容转换成只读目录，供播放器、WebDAV 客户端和本机挂载使用。桌面与 Cloudflare Worker 共用核心和管理页面；网易云、QQ 是示例插件。

## 使用场景

- 本地播放器通过挂载盘浏览、扫描和播放，使用已读取的音频缓存。
- 手机播放器、OpenList 等通过 WebDAV 访问桌面或云端音乐库。
- 复制或下载导出的音乐文件，文件携带来源可提供的音乐资料、封面和歌词。
- 同一插件连接多个账号或服务器，各自保存授权、音质、内容和配置。
- 用目录整理、文件名模板与自动更新规则组织自己的音乐库。

桌面提供托盘、登录自启和后台自动挂载；管理页面与 WebDAV 分别配置访问范围和凭据。Worker 提供管理页面和 WebDAV，桌面也可挂载远端 Worker。

## 功能要求

本表定义用户可观察的行为；实际平台、格式和验证边界见[兼容性说明](verification.md)。

| 编号 | 功能 | 可观察的验收结果 |
|---|---|---|
| FR01 | WebUI 认证 | 按插件声明展示认证步骤；网易云与 QQ 示例在桌面及 Worker 均有至少一种通过验证的扫码通道，显示等待、成功、过期或失败 |
| FR02 | 会话保存 | 按实例保存有效授权，后台重启或 Worker 再次实例化后可继续使用；失效时按插件流程重新认证 |
| FR03 | 示例歌单分类 | 网易云与 QQ 示例的自建、收藏分别完整分页，不按名字猜分类 |
| FR04 | 示例喜欢的音乐 | 示例插件提供对应内容源，取得完整曲目；曲目数与导出文件数分别统计 |
| FR05 | 示例发现 | 示例插件提供每日推荐与推荐歌单，按有限内容快照刷新 |
| FR06 | 内容与顺序 | 完整读取内容、保留来源顺序和同名项；示例插件保留同曲在歌单中的重复位置 |
| FR07 | 音频读取 | 格式、扩展名和读取元数据正确，支持流式播放、HEAD、随机范围读取与取消 |
| FR08 | 示例音质模式 | 每个示例插件实例分别配置单/多版本，插件按实际音质导出可区分的文件 |
| FR09 | WebDAV 与 OpenList | 用标准 WebDAV 驱动列目录、打开歌曲并向前或向后拖动 |
| FR10 | 一键挂载 | 桌面通过 WebUI 完成挂载，不要求用户配置 rclone；系统驱动条件见兼容性说明 |
| FR11 | 挂载管理 | 页面查询状态、正常卸载；失败可诊断，重复启动不产生无意重复挂载 |
| FR12 | 远程挂载 | 桌面 WebUI 配置 Worker 等远端 WebDAV，并在本机挂载 |
| FR13 | 刷新与失败 | 按实例或内容源刷新，失败保留最近成功目录并显示过期状态；实例间互不串状态 |
| FR14 | 基本访问控制 | 来源凭据不交给播放器；只读 DAV 访问不能管理插件、实例、认证或设置 |
| FR15 | 状态诊断 | 区分插件缺失/不兼容、实例需认证、限流、网络或挂载故障；来源专属原因由插件报告 |
| FR16 | 发布 | 提供所支持目标的桌面包、Worker 部署模板、插件作者包、源码、依赖许可和使用说明 |
| FR17 | 拖拽目录布局 | 创建分组、选择内容源、拖拽改变层级；保存后 WebDAV 按此展示，刷新不覆盖布局 |
| FR18 | 示例音质缺失策略 | 每个示例插件实例可选隐藏或自动回退；实际标签正确，同一实际音频不重复导出 |
| FR19 | 安装与更新插件 | WebUI 支持预构建插件包上传或发布地址安装、用户主动更新；无需使用者自行编译核心或前端 |
| FR20 | 多个来源实例 | 同一插件配置多个实例，连接配置、认证、来源设置及内容互相隔离 |
| FR21 | 插件配置与认证界面 | 新插件声明配置字段、校验和认证步骤，核心用通用表单、二维码、链接/验证码等承载，无平台专用前端分支 |
| FR22 | 插件兼容 | 安装前显示插件接口及宿主兼容情况；不兼容时给出明确结果，示例插件按双宿主验收 |
| FR23 | 移除与恢复 | 移除插件保留实例配置和布局引用，标记缺失并停止读取；重装兼容版本可恢复，删除实例数据另作操作 |
| FR24 | 公开插件合同 | 独立插件仅经公开接口提供入口、目录和音频，不修改核心；没有扫码、歌单或音质概念的来源也能接入 |
| FR25 | Worker 自动部署 | 安装、更新、移除插件时由后台自动发布 Worker 新版本；按免费计划设计执行预算，保留状态并报告失败和切换影响 |
| FR26 | 自动更新规则 | 支持固定时刻、自定义间隔及时区；明确单目录、完整子树或整个实例范围，集中查看/暂停，复用持久刷新和旧快照 |
| FR27 | 自定义命名模板 | 用户编辑模板自动填充插件可选提供的资料，预览与DAV/挂载一致；不因改名改变实际音频身份或来源配置 |

FR03—FR05、FR08 和 FR18 为网易云与 QQ 示例插件的验收要求，不是所有第三方插件的必选能力。示例插件分别处理“平台确认无完整播放权限”和“所选音质不可用”：前者隐藏，后者按实例设置处理。核心展示插件报告的原因，不根据网络失败、大小未知或待解析自行推断无权播放。

## 责任与边界

插件负责平台协议、认证、音质和音乐资料，核心负责实例、完整快照、目录组织及最终文件合同。音质按实例保存；没有歌单、扫码或音质概念的插件也能接入。补标签是可选能力，可由插件自行实现或复用工具包。示例插件补充来源可提供的歌名、多位歌手、专辑、专辑艺术家、日期、曲号/碟号、封面与歌词，缺失资料不猜测。

刷新与用户整理的目录相互独立。失败保留最近成功内容；目录清单、音乐资料、不可变文件表示和已读音频分别缓存。文件公开后，其大小、内容身份与 Range 必须对应相同字节。

音乐库以只读、自用为范围。播放器、云端歌单编辑、转码和离线下载任务管理不属于当前产品；普通复制导出仍由文件访问支持。管理账号、播放器凭据和来源授权分别拥有自己的生命周期。

接口、模块和时序以[架构](architecture/README.md)、[公开插件合同](architecture/plugin-interface.md)和[图表](architecture/diagrams.md)为准。配置与使用步骤归对应指南，本页不再复制技术设计和实施阶段。
