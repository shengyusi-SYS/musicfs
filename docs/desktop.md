# 桌面运行、挂载与备份

[English](en/desktop.md)

MusicFS 在电脑上运行后台，用浏览器管理来源和音乐目录。首次添加来源见[使用指南](user-guide.md)，播放器接法见[客户端连接](clients.md)。

## 打开、常驻和退出

解压完整安装包，Windows 打开 `MusicFS.exe`，Linux 运行 `musicfs`。浏览器会直接进入管理页。关闭网页后，服务和挂载继续运行；再次打开程序会回到已有后台。

Windows 双击托盘图标打开页面，右键可打开手机访问或退出 MusicFS。退出时若文件正被使用，先关闭使用挂载文件的播放器或复制任务，再重试。

「设置 → 启动与挂载」可调整：

| 设置 | 默认 |
|---|---|
| 登录系统后启动 | 开启 |
| 手动启动时打开管理页面 | 开启 |
| 自启时打开管理页面 | 关闭，静默驻留 |
| 启动时恢复自动挂载 | 开启 |
| 暂时失败后后台重试 | 开启 |

自动挂载在后台恢复，不阻塞页面打开；暂时失败时最多尝试3次，每项也可手动重试。更新程序位置后，再运行一次新版即可更新自启入口。Linux 托盘需要桌面提供 StatusNotifier 支持。

无桌面、NAS 或 SSH 使用[远程运行](headless.md)。终端和托盘可用 `--language en` 或 `--language zh-CN` 指定语言；浏览器独立记住自己的选择。

## 登录与两种局域网访问

首次从程序打开可直接进入，账号密码在「设置 → 登录账号」按需创建。忘记管理密码时，从程序重新进入设置即可修改。

| 想做的事 | 在哪里开启 |
|---|---|
| 用手机或另一台电脑管理 | 设置 → 管理页面访问 |
| 让播放器读取音乐 | 连接与挂载 → WebDAV 播放器 |

两者分别设置访问范围和端口，默认仅本机。只让播放器连接时，只开放 WebDAV 即可。端口填0自动选择；改 WebDAV 端口后在播放器中更新地址，改管理端口不会移动读取入口。

手机管理扫码从「服务操作 → 手机访问」进入；播放器扫码从 WebDAV 页的「扫码导入」进入。前者登录管理页，后者包含播放器读取账号和密码。两种扫码都可选择可达的网卡地址。

## 挂载为磁盘

在「连接与挂载 → 磁盘挂载」添加当前 MusicFS，或填写远程 WebDAV 地址与凭据。挂载发生在页面标明的后台设备上。

| 系统 | 准备与位置 |
|---|---|
| Windows | 按页面提示安装 WinFsp；填写空闲盘符，如 `M:`，或留空自动分配 |
| Linux | 准备 FUSE、`/dev/fuse` 和 `fusermount3` 或 `fusermount`；选择空目录 |
| macOS | 从源码构建，挂载使用系统 NFS 工具与相应权限 |

名称默认为 MusicFS，可在添加时自定义，也可从挂载菜单重命名。自动挂载开关按每项保存；「卸载」只停止本次，「移除挂载」删除定义及所属缓存。「重新挂载」沿用设置。

目录和音频缓存可在挂载菜单调整。修改或清理活动挂载的缓存会正常重新挂载。直接 WebDAV 的共享读取缓存在 WebDAV 页单独管理；完整使用方法见[使用指南](user-guide.md#更新歌单和管理缓存)。

## Windows 资源管理器原生映射

需要使用资源管理器的「映射网络驱动器」时，打开「WebDAV 播放器 → Windows 资源管理器原生映射」：

1. 启用本机 HTTPS。
2. 点击「完成 Windows 连接设置」，接受系统权限提示。
3. 将显示的 HTTPS 地址和读取账号密码填入资源管理器。

连接设置会信任本数据目录的本机证书、启动 WebClient，并按需将其单文件上限从默认50,000,000字节提高到4GiB−1。这影响该电脑的所有原生 WebDAV 连接，应用时会重连 WebClient；「恢复原文件上限」可恢复 MusicFS 修改前的值。停用 HTTPS 或退出程序会保留该上限设置。

本机 HTTPS 供运行后台的电脑使用，局域网播放器使用 WebDAV 页显示的局域网地址。App 内的 rclone/WinFsp 挂载支持 HTTP/HTTPS，不受上述原生文件上限影响。

## 数据备份与常见问题

终端 `--headless` 或 `--no-open` 输出实际数据目录，也可用 `--data /你的/目录` 固定位置。默认位于当前用户的系统应用数据目录，和程序解压位置分开。

备份时正常退出，复制整个数据目录即可，包含账号会话、插件、目录、连接和挂载设置；恢复后用 `--data` 指向该目录。音频片段缓存可按需保留，完整歌曲另行复制或下载。

| 现象 | 下一步 |
|---|---|
| 页面关了，想重新进入 | 再次运行程序，或双击 Windows 托盘图标 |
| 挂载失败 | 查看挂载列表的原因，确认 WinFsp/FUSE 和位置后重新挂载 |
| 另一设备不能连接 | 确认开启的是对应入口的局域网访问，并选用可达地址 |
| 来源显示需要登录 | 在该来源重新登录；QQ 与微信可能对应不同内容账号 |
| 启动失败 | 查看数据目录的 `startup.log`、`launcher.log` |
| 挂载读取异常 | 查看数据目录的 `mounts/rclone.log` |
| WebDAV 或后台读取异常 | 查看 `logs/musicfs.log`，有错误编号时可对应查询 |

在「设置 → 日志与诊断」选择「详细」，复现后下载日志。应用与挂载日志分别配置，立即生效，无需重启；普通读取默认不逐次记录。详见[IO 诊断](architecture/logging.md)。

反馈问题时附 MusicFS 与插件版本、系统、使用方式、出错步骤和对应错误信息即可。
