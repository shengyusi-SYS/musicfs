# 音乐库树形工作区核对

2026-10-23，`0.1.0-dev.25` 源码预览。设计与取舍见[共用管理界面](../architecture/web-ui.md)。本轮不重打发行包，已发布的 dev.24 归档保留原样。

## 内置浏览器

WSL 本地服务 `http://127.0.0.1:8787/`，使用独立 SQLite 演示数据：两个明确标为示例的来源、入口与嵌套目录，以及128个演示文件。未使用真实音乐账号或读取音频。

| 用户路径 | 结果 |
|---|---|
| 来源树 → 喜欢的音乐 | 在主区直接看到文件，不再转到另一页面；树中不展开歌曲 |
| 歌曲搜索、返回、重载 | 名称筛选保留顺序；浏览器返回和重载保留选中目录 |
| 来源/目录设置 | 同一侧栏切换来源设置、自动更新、文件命名；切换目录关闭旧上下文 |
| 命名预览 | 正确使用当前目录，未变化名称不重复显示，不增加警告块 |
| 新增来源 | 侧栏直接显示名称与插件配置，关闭可回到原目录 |
| 目录整理 | 左树右内容；新建文件夹、原位改名和连续撤销通过，撤销回原值后保存按钮恢复禁用 |
| 约390px小屏 | 目录抽屉可选中并自动关闭；设置页签和时间/时区表单可达，没有横向页面溢出 |

窄屏关闭目录抽屉时曾捕获树组件焦点事件访问已清空引用。移除外层提前卸载条件，交由 Drawer 的 `destroyOnHidden` 管理退出；重走同一有界路径，未出现新控制台错误。未增加延时或捕获异常掩盖问题。临时视口设置已恢复，内置浏览器保留正常窗口预览。
