# Worker 云端验收

2026-10-20 起，使用用户授权的 Cloudflare 付费测试账号、独立 Worker 和 D1 验证。操作在 WSL 内执行，扫码使用内置浏览器；未调用 Windows 宿主。以下保留功能证据和边界，具体账号、域名、资源 ID、会话、机器路径及私有原始响应不作为公开文档内容。

## 已验证的使用链路

| 范围 | 结果 |
|---|---|
| 首次部署 | 全部 D1 迁移、管理页静态资源、管理 API、WebDAV 目录读取通过 |
| 凭据分工 | 管理令牌可管理服务，WebDAV 凭据仅用于读取；插件发布凭据保留在 Secrets |
| 插件生命周期 | 示例插件由 Worker 自行安装、更新、移除和重装；一次候选代码发布失败后旧安装继续可用 |
| 数据保留 | 插件变更保留实例、配置、播放器布局、D1 身份、绑定、Secrets 和原有运行设置 |
| 多实例与独立插件 | 同插件的两个实例配置互相独立；仓库外作者包无需重编译核心即可接入 |
| 来源授权 | QQ 微信通道与网易云 App 扫码后可跨请求复用会话，显式退出后重新登录通过 |
| 分类目录 | 已有自建、收藏、推荐歌单列表可刷新；空收藏集合按实际账号内容判断 |
| 内容与音质 | 有限每日推荐、单张歌单及单/多版本策略通过；隐藏、回退、合并分别统计 |
| 文件读取 | 代表性 WAV、MP3、M4A 的 HEAD、全文或 Range 读取通过，大小和格式对应实际内容 |
| 核心升级 | 从实际部署读取注册表和插件精确修订，仅替换核心与页面；实例、授权及已有读取保留 |

QQ 账号中收藏的专辑不等于收藏歌单，未为验证强行制造非空集合。目录中的曲目数、可导出文件数、隐藏和音质统计分别记录，不把上游有歌曲等同于当前账号有可读取音频。

## 部署与切换经验

- 收窄 Wrangler 模块规则后，页面、SQL 和发行说明通过各自入口提供，不再重复上传为运行模块。
- 核心升级同时保留 D1 和可执行插件；仅保留数据库、用初始注册表覆盖现有代码会丢失已安装插件的运行能力。
- 后台发布先记录持久意图，再上传并核对代码；不能把响应丢失直接当成发布未发生。
- 切换期间出现过短暂的 503 与 Retry-After，随后原文件恢复。这里保留可观察行为，不把它描述成所有连接均无中断。
- 付费账号的成功结果不证明免费 CPU、D1 查询预算或大目录成本。

## 验证粒度

采用已有账号、现有小集合和代表性文件，串行推进；不进行压力测试、批量下载或为覆盖音质遍历整库。不重复制造已由离线 SQLite/D1 回归覆盖的异常排列。

真实云端结果证明上述使用链路；本地 workerd、受控替身、既有桌面整库结果各保留原有证据等级。免费计划和其他客户端边界见[验收台账](../verification.md)。

一键部署入口、近期首次访问及登录验证见[一键部署记录](worker-oneclick.md)，当前部署操作见[Worker 指南](../worker.md)。

## 核心与WebUI升级保留现有插件

组装工具从实际 Worker 读取完整模块，保留注册表及插件精确修订，替换核心和页面。升级前后实例、配置、布局、授权及运行设置一致；部署后的模块摘要对应输入，代表性合成文件 HEAD 通过。未为升级重新扫码或刷新来源。

## 音乐资料功能原地升级

API 0.1.6、schema 8 及当时的 QQ/网易云示例插件曾在已有付费测试实例上原地升级，保留实例、配置、布局和会话。页面、合成 WAV 的 HEAD 与 16 字节 Range 通过；没有把部署成功视为所有格式的真实标签和播放器验收。

## 云端OpenList与普通播放器

OpenList 4.2.7 的正式 WebDAV 驱动以 native_proxy 连接既有云端目录，独立 mpv 0.41.0 读取代表性 MP3。首次定位阻塞先用本地合成流隔离，收敛到 WSL 的 mpv/Pulse 暂停恢复组合；未据此修改 MusicFS 或追加音乐平台请求。

保持 Pulse 音频流的一次性验收包装器下，193.3 秒、48kHz 双声道文件实际解码，播放时钟前进，五次前后定位通过。加载到播放约 9 秒，各次定位恢复约 4.8—12.7 秒，HTTP 范围包含非零及后退读取。没有主观听音证据，也不称为低延迟通过；该包装器未成为产品默认，其他原生系统不由此推断。
