# 界面重构走查

2026-10-22，针对仓库当前前端源码。使用 Vite 正式构建和独立 WSL 桌面服务，临时 SQLite 数据、随包 sample 与仓库认证夹具。重构比较见[各环节取舍](../../outputs/musicfs-ui-ux-decisions.md)，当前模块与流程见[界面设计](../architecture/web-ui.md)。

## 实际操作

| 使用环节 | 实际结果 |
|---|---|
| 首次添加 | 从空状态进入添加流程，安装 sample ZIP；文件选择后自动显示信息，安装后可直接添加来源。随后去掉了缺插件时的中间空弹窗。 |
| 创建来源 | 选择已有插件、填写 sample 目录名称、提交，直接打开内容浏览。唯一来源自动选择，可选显示名称折叠。 |
| 登录 | 创建二维码模式认证夹具，自动打开步骤；轮询进入输入，提交测试码，成功后显示账号；点击浏览内容进入对应来源。另验证重新登录后关闭、再打开进行中步骤，仍可完成并显示成功。未请求真实平台二维码。 |
| 目录浏览 | 默认布局直接打开来源、歌单和 WAV 文件条目，未先建立自定义布局。面包屑逐层返回。 |
| 整理目录 | 新建文件夹、加入已选来源内容；关闭抽屉、切换页面、使用浏览器后退，草稿仍在；保存后实际目录变为新布局。 |
| 大目录找内容 | 临时布局添加 60 个本地分组，共 61 项、两页。输入指定名称后仅剩目标项；浏览器网络事件中筛选没有新增请求。随后恢复原布局。 |
| 挂载入口 | 打开添加窗口，默认只展示来源和位置；缓存和可选名称在更多设置内。未执行系统挂载。 |
| DAV 连接 | 地址、用户名和密码分别展示；复制地址并读取剪贴板核对成功；局域网设置展开后才出现。未修改网络设置。 |
| 窄屏 | 实测 CSS 视口约 389×843；四项导航、连接信息和操作可用，文档宽度等于视口宽度。修正了 Ant Design 菜单伪元素占据网格位置导致的换行。 |
| 桌面 | 实测 CSS 视口 1280×800；目录和连接页正常展示，无横向溢出。已观察连接页浏览器日志，未见 error/warn。 |

这次走查修正了重复空状态按钮、无关技术 ID、分散的创建与登录入口、目录编辑抢占浏览、长连接说明、创建挂载时过多的参数，以及页面切换丢草稿等问题。另修正了配置失败结果被当作成功、过时插件操作记录锁住安装，以及刷新缓存统计覆盖未保存输入的问题。

## 检查和边界

三套 TypeScript 检查、模块边界检查（252 个模块、1,042 条依赖）及前端构建通过。现有布局树的两项回归、六个断言通过。没有新增 UI 框架、依赖或后台接口。

Windows 自动盘符复用已有 `*` 挂载合同，只调整表单默认输入；未重新运行 Windows VM 或系统挂载。没有请求音乐平台、部署 Worker 或调用 Windows 宿主。本次尚未重新打包桌面发行物，dev.12 归档保持原身份。
