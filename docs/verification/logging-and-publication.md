# IO 日志与公开资料核查

2026-10-24，MusicFS。重点为对外 WebDAV，以及来源请求、文件流、共享缓存和 rclone 链路。

## 实现与验证

- LogTape 统一两宿主的结构化记录、请求上下文和级别，桌面文件轮转采用官方 file sink，rclone 使用原生轮转。
- WebDAV 与上游连接区分响应就绪、字节流完成、取消和流中断。缓存标识 native/bypass，跨原生进程使用不可变资源键辅助关联；不声称由进入 VFS 推断命中。
- 正常 IO 默认不记录；debug 和重复 IO/HTTP 故障按事件限量，每分钟最多 20 条并汇总。未增加持久日志数据库、平台查询或逐块日志。
- 有界离线测试确认：错误编号关联、上下文传递、正文不变、无预读、取消传播、中断单次记录、限量及抑制计数；正式 workerd/D1 支持原生 async_hooks，既有 Range 和缓存回归通过。
- 本轮未做平台压测、真实歌曲扫描、Windows 网络排查或整库计时。

设计与排障入口见[日志设计](../architecture/logging.md)，云端访问旅程见[一键部署记录](worker-oneclick.md)。
