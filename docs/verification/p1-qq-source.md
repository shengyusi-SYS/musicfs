# QQ 真实授权、目录与 DAV 首条链路

日期：2026-10-20。环境：Linux x86_64、Bun 1.4.3、Node 24.19.0、本地 Miniflare/workerd、SQLite/D1。本记录证明当前开发预览的一条真实链路，不表示 P1 全部出口或完整 QQ 示例已完成。

## 版本与责任

插件 `org.musicfs.qq@0.1.0-alpha.2`，公开合同 0.1.1，SDK `@yakult-green-tea/qq-music-api@3.3.3`。通过 npm 正式发布包核查源码与许可，使用 `/serverless`，未导入会启动 Koa 的根入口。npm 发布包完整性见原[调查补充](../research/qq-api.md)。插件 ZIP 为 124,275 字节，SHA-256 为 `d1806c370a5e0866cc7d3158da696e5a6f9007571e52c383075b2ab7bbd5191d`。

来源认证、SDK、分页、可读性判断、文件身份与取流均在 `plugins/qq`。核心只增加通用 `waiting.qrImage`，页面按公开步骤显示受限内嵌 PNG/JPEG，没有按 QQ ID 判断的路径。

## 真实用户与协议路径

1. 通过正式插件安装 API 安装预构建包，在共用页面创建实例并打开授权窗口。SDK 返回真实二维码；用户明确答复“现在扫码”，在手机 QQ 确认。窗口显示授权已完成，已确认会话写入实例私有状态，待扫码状态清除。
2. 停止并重新启动开发服务，再用保存的状态调用真实 `/login/status`，账号校验成功。随后经正式 API 更新 alpha.1 → alpha.2；后续 `roots` 和 `refresh` 仍成功，不需要再次扫码。更新使旧公开交互操作失效，与私有会话是否继续有效分别处理。
3. 真实喜欢列表返回总数 **0**，保留空结果。每日推荐返回 **30** 首；当前单一 128k 规则取得 **5** 个播放地址，其余条目返回明确不可读取结果并被隐藏。喜欢列表的非空多页与重复位置目前由可控测试覆盖，真实账号的空列表不能证明多页平台验收。
4. 保留已有布局，增加“QQ 真实验证”内容源入口。共用页面显示 5 个真实文件及原歌曲位置编号，未新增平台页面。二维码、账号截图、临时音频和测试路径只在 `/tmp`；仓库不保存账号标识、凭据或媒体 URL。
5. 经正式 DAV 路径，HEAD 返回 `audio/mpeg`、大小 **2,570,671**，无响应体；完整 GET 得到同样长度。首、中、尾、后缀与开放范围共 5 次 206 均与完整文件逐字节一致；越界范围返回 416 和正确总长。完整 SHA-256：`df13ddcb250d1d644fe766deb9d8cbe807ee7b0111924cfd9e240d944baef700`。
6. `ffprobe` 识别为 MP3、44,100 Hz、双声道、约 160.576 秒、128,072 bit/s。此项是媒体格式检查，未操作普通播放器完成实播与拖动。
7. 已校验的 rclone v1.75.2 对同一真实目录完成列文件和大小、完整下载，以及首→中→尾→中→首 5 次偏移读取，全部与完整文件一致。没有执行系统挂载。

## Worker 与回归

首次直接从 SDK 源码组装本地 Worker 时，启动失败于日志模块的 `process.env`。采用作者构建时的固定日志设置消除该运行时依赖；探针改为导入实际构建的安装模块。本地 workerd 未设置 Node 兼容开关，插件初始化和两个独立密钥通过。

显式选择刚授权的桌面开发实例，只读取出其私有状态，恢复到临时本地 D1。经正式管理接口调用真实 QQ：账号校验成功，完整每日推荐快照得到同样 5 个文件。临时 D1 在探针结束后删除。这证明本地 workerd 的会话恢复和真实目录调用；没有在 Worker 中重新扫码，没有执行云端部署或云端音频验收。

| 检查 | 结果 |

| `bun run check` | 76 项测试、315 次断言；三组类型检查；83 个模块、237 条依赖，无边界违规 |

## 剩余范围与下一步

以下是 alpha.2 记录当时的缺口；alpha.3 的原始分类与推荐歌单进展见[后续记录](p2-qq-catalog.md)。

- 接入自建/收藏的真实来源分类。SDK 公共 `/user/playlist` 已合并去重，不能从输出可靠还原类别，也不能按名称或所有者猜测；需在插件内收敛保留原始类别的 SDK 适配入口，避免复制签名/加密/传输实现。
- 完成推荐歌单、可配置单/多音质、缺失策略、实际质量标签与同一出现位置内的文件去重；当前仅固定单一 128k。
- 完成会话续期的协调与条件合并、失效重登、微信真实扫码；SDK 元数据请求的取消传递仍有缺口。媒体请求使用 `ctx.fetch` 和信号，范围/错误/取消由当前测试核对。
- QQ 的真实 Worker 扫码、云端目录与音频，网易云完整示例，OpenList/普通播放器、四个桌面目标运行、挂载、发布与资源验收继续保持待完成。
