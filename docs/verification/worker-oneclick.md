# Cloudflare 一键部署接入

2026-10-24，MusicFS 0.1.0-dev.31。入口为根目录的 Wrangler 配置、`bun run build` 和 `bun run deploy`，中英文指南及 README 按钮指向公开仓库。

| 范围 | 结果 |
|---|---|
| 部署组装 | 保留自定义 Worker 名称、已创建的 D1、Secrets 声明及额外配置；只在远端 Worker 不存在时采用初始插件集 |
| 已有部署升级 | 保留实际注册表和插件精确修订，重新组装核心与页面；迁移按 DB 绑定执行 |
| 自身插件下载 | 同域 `plugin-packages/` 安装请求直接使用 ASSETS，外部插件地址继续通过 HTTP 下载 |
| 本地回归 | 部署、升级、HTTP 插件安装、正式 Worker 装配和发行源码检查通过；类型、依赖边界及中英文检查通过 |
| 真实云端 | 临时 Worker/D1 首次部署成功；自身 ZIP 下载、检查、安装完成；再次部署后安装仍激活且修订不变 |

真实验证关闭 Cron，只安装合成音频示例，不访问音乐平台。首次发现自身地址回源下载失败，修复后完成上述旅程；两轮临时资源均已删除。

Cloudflare 网页中的账号连接、仓库复制及资源创建表单尚未实际走查；这部分使用官方部署按钮流程。免费计划 CPU 和大目录行为沿用原验收范围，不由本次付费账号部署结果推断。
