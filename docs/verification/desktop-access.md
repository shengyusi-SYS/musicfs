## 已有证据

| 范围 | 核对结果 |
|---|---|
| 管理认证 | Bun SQLite 与本地 workerd/D1 的密码设置、登录、记住登录、ticket 兑换、独立会话退出、密码变更通过；Worker 实际多模块产物的 Cookie 管理 API 接线通过。 |
| 启动与自动挂载 | 默认偏好、手动/登录启动分别控制页面、重复启动复用后台、ticket 自动进入通过；恢复启用项、有限重试、手动操作接管本次、拒绝退出后恢复通过。 |
| 网络即时生效 | 本机与 LAN 监听切换、端口变更、失败保留原入口通过；设置请求和既有响应能完成，不强断正在传输的响应。 |
| 浏览器旅程 | 独立空服务中走通启动自动进入、设置、密码登录、退出、未开 LAN 的手机引导、已开 LAN 的二维码和网卡选择。未扫码连接真实手机。 |
| 原生 helper | Linux musl 静态及 Windows x64 GUI 子系统交叉构建；Linux D-Bus fixture 的 ready 和父输入关闭后退出通过。参数编码与 Bun 桥接通过。 |
| 既有入口 | 管理插件/来源/目录/DAV 正常链路、自动挂载与版本化打包定向回归通过；类型与模块边界通过。 |

浏览器走查修正两处实际接缝：退出登录保留 access 查询订阅并刷新账号状态；正常退出被挂载拒绝时恢复自动挂载协调，避免永久关闭。旧管理 API 的 Bearer 专用错误预期调整为统一会话入口的 401，DAV 凭据仍不能访问管理端。
