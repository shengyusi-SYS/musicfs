# 共用管理界面

## 视觉与交互基线

2026-10-20 用户已确认：Ant Design、浅色、青绿色主操作色、紧凑但留白清楚的左侧导航布局。桌面与 Worker 共享一套 React/Vite 构建，不执行插件提供的前端代码。

Design Read：面向个人用户的管理工具，从零建立界面；熟悉的工具布局，信息密度 7、视觉变化 2、动效 2、素材依赖 1、品牌约束 3（各项满分 10）。固定导航与分组帮助扫描，授权和配置使用渐进展示；仅使用真实状态。页面主要在桌面浏览器近距离阅读，同时保留窄屏操作入口。不需要营销图像或外部字体。

- 页面职责：数据源负责独立实例；插件负责安装与生命周期；目录布局负责发布的分组；服务连接负责接入已有客户端。
- 色彩：工作区 `#f4f6f5`，面板 `#ffffff`，正文 `#1d302e`，辅助文字 `#60716e`，边界 `#dce4e1`，主操作 `#147d74`。错误/警告沿用 Ant Design 语义色。
- 字体：本地中文系统字体；正文 15px，标题 30–40px，辅助信息 12–13px。8px 间距基线。
- 控件圆角 8px、面板 12px；以边界建立层次，避免堆叠阴影。仅保留组件状态反馈，并支持减少动效。
- 内容量：标题、目的说明与主操作在同一区域，实际列表占据主要视野。加载、错误、空内容分别显示，不用虚构指标填充。

## 模块关系

`src/web` 仅依赖浏览器库、公开插件 DTO 与 `src/contracts/management.ts`；不能导入核心或宿主。TanStack Query 管理服务器请求状态，组件保留表单/布局草稿。RJSF Ant Design 主题承载 JSON Schema，后端插件校验仍是权威。

管理令牌只用于 `/api` Bearer 请求，来源私有授权不返回浏览器。启动入口可通过 URL fragment 提供管理令牌，页面立即移除 fragment；当前标签会话使用 sessionStorage。切换令牌时清空查询缓存。DAV 读取凭据与管理令牌分离。

首版布局经用户确认后，已接入插件/实例、内容源刷新、布局草稿/拖动/发布及连接信息，范围见[首轮接线记录](../verification/p1-webui.md)。通用认证窗口随后接入二维码、链接、Schema 输入、轮询、错误、取消和重启恢复；以插件能力声明显示入口，认证请求不返回私有状态。QQ 的单/多音质由插件 Schema 生成，目录行按插件声明的标签显示计数及最近成功时间；不添加平台专用页面。目录状态请求只读快照，刷新及配置/插件生命周期操作使相关查询失效。浏览器结果见[音质/计数记录](../verification/p2-qq-quality.md)及[认证记录](../verification/p1-authentication.md)。当前实现与剩余验收统一见[台账](../verification.md)，此处只维护页面职责。

已发布目录用现有Ant Design List内建分页，每页50项，提供总数和跳页，切换路径时重置页码，小目录隐藏分页。完整目录与顺序由后台合同保持，页面分页只限制同时渲染的条目；不增加服务端分页接口或虚拟滚动依赖。[本地UX证据](../verification/p3-local-ux.md)

插件安装弹窗先只读检查ZIP或发布地址，显示插件身份、API范围/当前版本、支持宿主/当前宿主；兼容后再提供安装或更新。输入变化清空旧结果，检查和安装期间禁用编辑。检查与安装共用后端归档/semver规则，没有另一套前端版本解析；安装时仍重新校验，发布地址会重新下载。
