# 在 NAS 或远程机器上运行

解压 Linux 发行包，在那台机器上运行：

```sh
./musicfs --headless
```

终端会列出管理地址、WebDAV 地址、数据目录，以及一次使用、3 分钟有效的登录链接。Linux 无图形会话或通过 SSH 启动时会自动采用这个模式，不启动托盘或注册桌面自启。服务在后台运行，关闭 SSH 后继续工作。

## 第一次打开管理页

默认两个入口都只监听运行 MusicFS 的机器。终端会给出带实际端口的 SSH 转发命令，将其中的 `<用户名@服务器>` 换成平时的登录地址，在自己的电脑执行并保持窗口打开，然后打开登录链接即可。

例如终端显示管理端口为 39123：

```sh
ssh -N -L 39123:127.0.0.1:39123 san@my-nas
```

转发只用于管理页面，WebDAV 仍使用自己的端口。若本地该端口已被其他程序使用，可以改用 `-L 8787:127.0.0.1:39123`，再将登录链接的端口改为8787。

登录后可以安装来源插件、扫码连接音乐账号、整理目录，并在「设置 → 登录账号」按需设置用户名和密码。来源二维码显示在自己的浏览器中，不需要服务器连接显示器。

## 希望同一网络直接访问

启动时也可指定管理页允许局域网访问：

```sh
./musicfs --headless --management-access lan --management-port 8787
```

打开终端列出的局域网登录链接，之后可用设置好的账号密码登录。手机管理入口仍由「手机访问」提供二维码。

要让播放器连接，单独开放 WebDAV：

```sh
./musicfs --headless --dav-access lan --dav-port 8788
```

在「连接与挂载 → WebDAV 播放器」复制地址和读取凭据，或扫码导入播放器。只开放 WebDAV 时，管理页面继续仅本机访问。

以上命令会保存设置，也能用于正在运行的同一后台；未指定的设置保留。管理端口和 WebDAV 端口应不同。端口填0会自动选择，并尽量在以后启动时复用。通过 SSH 转发修改管理端口后，要按新端口重新建立转发。

## 再次访问、挂载与停止

- **登录链接过期或已经使用：** 再次运行 `./musicfs --headless`，复用已有服务并显示新链接。自定义过 `--data` 时仍使用同一目录，终端也会打印可直接复制的完整命令。
- **挂载位置：**「磁盘挂载」显示实际设备名称和系统。远程打开管理页，挂载仍发生在运行 MusicFS 的机器；自己的电脑可以用播放器连接 WebDAV，或在自己的电脑运行 MusicFS 来挂载远程 WebDAV。
- **停止后台：** 管理页「服务操作 → 退出 MusicFS」。关闭浏览器或 SSH 不会停止后台。

## 交给服务管理器运行

使用 `./musicfs --foreground --data /你的/数据目录`，程序留在前台，Ctrl+C 或 SIGTERM 正常停止；自动挂载仍在后台异步恢复。systemd 等服务管理器使用同一命令和固定的数据目录即可，不再由 MusicFS 注册桌面自启。管理器负责进程启动，MusicFS 负责已保存挂载的恢复。

如果同一数据目录已有服务在运行，`--foreground` 显示现有入口后退出，不再启动第二个后台。完整选项见 `./musicfs --help`。

终端和托盘语言可用 `--language en` 或 `--language zh-CN` 指定，例如 `./musicfs --headless --language en`。管理页面首次跟随浏览器语言，也可以在页面独立切换。
