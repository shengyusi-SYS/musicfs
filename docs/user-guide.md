# 使用 MusicFS

把歌单接进来，再交给你常用的播放器。本页对应当前界面，下载与版本见[发行说明](release.md)。

## 打开 MusicFS

解压完整桌面包，Windows 打开 `MusicFS.exe`，Linux 运行 `musicfs`，管理页面会在浏览器中打开并直接进入。macOS 的构建范围见[桌面指南](desktop.md)。

关闭网页后，服务和挂载继续运行。双击 Windows 托盘图标可重新打开管理页面，右键可查看手机二维码或退出 MusicFS；再次打开程序也能回到页面。

默认登录系统后静默启动，手动打开程序时显示管理页面。这些选项都在「设置 → 启动与挂载」。

## 登录和手机访问

需要账号密码时，在「设置 → 登录账号」创建。以后用用户名和密码登录，勾选「记住登录」可记住 30 天。退出登录只结束当前浏览器的会话，音乐和挂载继续运行。

手机先连接同一网络，在「设置 → 局域网访问」开启「局域网设备」并保存。打开页面「服务操作 → 手机访问」，扫码即可进入；多网卡时可选择手机能访问的地址。再次扫码可点击「更新二维码」。

## 连接音乐来源

1. 在「音乐库」点击「添加来源」。尚未安装插件时，会直接打开安装窗口。
2. 选择插件 ZIP，查看名称和版本后安装。桌面包附带的插件位于 `plugins/` 文件夹；也可以填写作者提供的下载链接。
3. 安装成功后会接着打开来源表单。填写显示名称和音质等设置，点击「添加并登录」。
4. 按来源提供的二维码、链接或输入步骤完成登录，再点击「浏览内容」。

同一插件可以添加多个来源，用于不同账号或音质设置。QQ 音乐请选择你收藏歌曲时使用的 QQ 或微信登录方式。

在树中选择来源后，点击「设置」调整配置，更多菜单可登录、退出账号或删除来源。退出账号会保留设置和目录，之后可以再次登录。

## 浏览和整理音乐

「音乐库」按来源、内容、播放器目录分栏。点击来源或目录查看内容；来源尚未加入播放器目录时也能浏览。拖动分隔线可调整栏宽，页面会记住它。窗口较窄时，点击顶部「来源」或「播放器目录」打开对应导航。

主列表可按名称搜索。首次打开的内容按需加载，需要准备文件信息时会显示「准备文件」。切换页面再回来会保留目录展开和浏览位置；重新进入最近浏览的目录，也会恢复搜索、勾选、页码和滚动位置。浏览器前进、后退和重载可回到当前目录。

想换一种排列方式，直接在工作区操作：

- 把来源入口、单张歌单或专辑从树、标题或列表拖进播放器目录的文件夹。多选后拖动其中一项，可一次加入多项；也可以点击「添加到…」选择位置。
- 点击播放器目录标题旁的新建文件夹图标，输入名称。双击目录名称，或从更多菜单重命名。
- 拖到文件夹中部会移入，靠上、下边缘会排序。也可用菜单的「移动到」「上移」「下移」；「移除」拿掉该目录入口。
- 修改后出现保存栏，可撤销、重做或放弃。点击「保存目录」让新布局生效，或直接点「保存并连接」继续接上播放器。

切换页面会保留未保存的修改。在「播放器目录」标题的更多菜单中选择「恢复按来源自动排列」并保存，可回到默认目录。手机上使用同样的添加按钮、目录菜单与保存栏。

## 在本地播放器中使用

打开「连接与挂载 → 挂载到电脑」，点击「添加挂载」。

Windows 可留空位置，自动分配盘符；也可以填写 `M:` 等盘符。首次挂载需要 WinFsp，页面提供安装入口。Linux 填写空的挂载目录，并安装系统 FUSE；macOS 挂载说明见[桌面指南](desktop.md)。

挂载完成后，将盘符或目录加入播放器，就可以播放或扫描入库；也可以像普通文件一样复制到本地。

挂载默认随 MusicFS 启动恢复，每项可单独关闭自动挂载。「卸载」只停止本次，下一次启动仍按开关恢复；「移除挂载」删除这条连接。重新挂载、目录缓存和读取缓存设置都在挂载的更多菜单中。

网络暂时未就绪时会在后台有限重试，可继续使用管理页面。自动恢复和重试都可在「设置 → 启动与挂载」调整。

要挂载远程 MusicFS 或其他 WebDAV，在添加窗口选择「远程 WebDAV」，填写地址、用户名和密码即可。

## 连接 WebDAV 播放器

打开「连接与挂载 → WebDAV 播放器」，将地址、用户名和密码填入播放器。三个字段都可以直接复制。

点击「修改账号密码」可自定义读取凭据，保存后立即生效。点击「扫码导入」可生成包含账号密码的 WebDAV 连接地址，供支持该格式的播放器扫码；也可以复制完整连接地址。密码明文显示。

手机或另一台电脑连接桌面服务时，在「设置 → 局域网访问」选择「局域网设备」并保存，即刻生效。将显示的局域网 WebDAV 地址填入播放器；固定端口便于播放器保存连接。播放器使用此处的读取凭据，管理账号用于管理页面。

OpenList 和其他客户端的具体设置见[客户端连接](clients.md)。

Windows 资源管理器的「映射网络驱动器」位于 WebDAV 页的「Windows 资源管理器原生映射」中。启用本机 HTTPS，完成连接设置后，使用显示的 HTTPS 地址。该操作会请求系统权限，重连原生 WebDAV 连接，并提高单文件读取上限；可在同处恢复原上限。

## 更新歌单和管理缓存

选中来源后点击「更新」，更新其全部内容；选中目录后点击「更新」只更新该目录。更新期间继续使用已有内容。

选中来源或目录，打开「设置 → 自动更新」，选择每天某时、每周指定日或自定义间隔，并选择更新范围。在主导航「设置 → 自动更新」集中查看、暂停和修改规则。关闭网页后后台继续执行。

需要重新取得封面、歌词等资料时，在歌曲目录「更新」旁的更多菜单选择「重新获取音乐资料」。它处理当前目录的歌曲，可查看进度或取消；普通更新仍优先复用已有资料。

| 设置位置 | 用途 |
|---|---|
| 挂载 → 更多 → 缓存设置 | 调整目录缓存、已读音频缓存容量和保留时间 |
| WebDAV 播放器 → WebDAV 读取缓存 | 管理直接连接本机 WebDAV 的播放器共用缓存 |
| 来源 → 设置 → 来源设置 | 调整插件提供的封面、歌词等音乐资料缓存 |

默认本机挂载目录保留一年，远程挂载目录保留一个月；本机内容更新后会主动更新挂载清单。音频片段和网易云、QQ 的音乐资料默认保留一年，可选择一个月、一年、长期保留或自定义期限。旧默认值随升级延长，其他设置保留。

修改来源的音乐资料保留天数不会清空原目录或缓存，新期限用于后续取得的资料；需要立即更新时使用「重新获取音乐资料」。

## 自定义音乐文件名

选中来源或目录，打开「设置 → 文件命名」，选择「自定义模板」。例如填写 `{{title}} - {{artist}}`，会自动生成 `晴天 - 周杰伦.flac`；字段按钮可以直接插入歌名、歌手、专辑等资料，扩展名自动追加。

预览满意后点击「应用命名」。来源设置作为默认，单个目录可以单独设置或跟随来源。首次改名后播放器可能重新入库；不含目录序号的模板可减少歌单增删时的路径变化。

音频缓存按需保存已经读取的片段，仍受容量限制。容量设为 0 可关闭新缓存，保留时间设为 0 则不按时间清理。挂载运行时修改或清理它的缓存，会重新挂载。

## 更新插件和桌面程序

在「插件」的更多菜单选择「更新插件」，安装新 ZIP 或填写下载链接。

更新桌面程序时，正常退出 MusicFS，换用完整新版目录，再打开程序。账号、设置和目录保存在用户数据目录中。

想把服务放在云端，参阅 [Worker 部署指南](worker.md)；想接入自己的音乐来源，参阅[插件作者指南](plugin-authoring.md)。
