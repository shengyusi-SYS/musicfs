# 使用 MusicFS

把歌单接进来，再交给你常用的播放器。本页对应当前界面，下载与版本见[发行说明](release.md)。

## 打开 MusicFS

解压完整桌面包，Windows 打开 `MusicFS.exe`，Linux 运行 `musicfs`，macOS 打开 `MusicFS.app`。管理页面会在浏览器中打开。

关闭网页后，服务和挂载继续运行。需要停止时，点击左下角「退出 MusicFS」；窄屏可从页面右上角的更多菜单退出。

## 连接音乐来源

1. 在「音乐来源」点击「添加音乐来源」。尚未安装插件时，会直接打开安装窗口。
2. 选择插件 ZIP，查看名称和版本后安装。桌面包附带的插件位于 `plugins/` 文件夹；也可以填写作者提供的下载链接。
3. 在插件列表点击「添加来源」。选择所需音质等设置，点击「添加并登录」。显示名称可以展开修改。
4. 按来源提供的二维码、链接或输入步骤完成登录，再点击「浏览内容」。

同一插件可以添加多个来源，用于不同账号或音质设置。QQ 音乐请选择你收藏歌曲时使用的 QQ 或微信登录方式。

已添加的来源可从更多菜单重新登录、修改设置或删除。退出登录会保留设置和目录，之后可以再次登录。

## 浏览和整理音乐

「音乐目录」默认按来源排列，打开文件夹即可浏览。首次打开的内容会按需加载；需要准备文件信息的来源会在页面给出「准备文件」入口。

较大的目录可以按名称搜索，结果保留原顺序。目录导航可逐层返回，切换页面后保留当前浏览位置。

想换一种排列方式，点击「整理目录」：

- 新建文件夹，加入喜欢的歌曲、歌单等内容。
- 拖动排序，选中目录修改显示名称。
- 点击「保存目录」，让播放器看到新布局。

切换页面会保留未保存的修改。选择「使用自动布局」并保存，可回到按来源排列的目录。

## 在本地播放器中使用

打开「连接与挂载 → 挂载到电脑」，点击「添加挂载」。

Windows 可留空位置，自动分配盘符；也可以填写 `M:` 等盘符。首次挂载需要 WinFsp，页面提供安装入口。Linux 填写空的挂载目录，并安装系统 FUSE；macOS 挂载说明见[桌面指南](desktop.md)。

挂载完成后，将盘符或目录加入播放器，就可以播放或扫描入库；也可以像普通文件一样复制到本地。

「卸载」保留连接，方便下次挂载；「移除挂载」删除这条连接。重新挂载、目录缓存和读取缓存设置都在挂载的更多菜单中。

要挂载远程 MusicFS 或其他 WebDAV，在添加窗口选择「远程 WebDAV」，填写地址、用户名和密码即可。

## 连接 WebDAV 播放器

打开「连接与挂载 → WebDAV 播放器」，将地址、用户名和密码填入播放器。三个字段都可以直接复制。

手机或另一台电脑连接桌面服务时，展开「局域网连接」，选择「局域网设备」并保存，重新启动 MusicFS。使用展开区域显示的局域网地址；填写固定端口，便于播放器保存连接。

OpenList 和其他客户端的具体设置见[客户端连接](clients.md)。

Windows 资源管理器的「映射网络驱动器」位于 WebDAV 页的「Windows 资源管理器原生映射」中。启用本机 HTTPS，完成连接设置后，使用显示的 HTTPS 地址。该操作会请求系统权限，重连原生 WebDAV 连接，并提高单文件读取上限；可在同处恢复原上限。

## 更新歌单和管理缓存

在来源的「浏览内容」中更新某个入口，或点击「更新全部内容」。在音乐目录内也可以更新当前目录。点击「定时更新」可选择更新周期；更新期间继续使用已有内容。

| 设置位置 | 用途 |
|---|---|
| 挂载 → 更多 → 缓存设置 | 调整目录更新间隔、已读音频缓存容量和保留时间 |
| WebDAV 播放器 → WebDAV 读取缓存 | 管理直接连接本机 WebDAV 的播放器共用缓存 |
| 来源 → 更多 → 来源设置 | 调整插件提供的封面、歌词等音乐资料缓存 |

音频缓存按需保存已经读取的片段。容量设为 0 可关闭新缓存，保留时间设为 0 则不按时间清理。挂载运行时修改或清理它的缓存，会重新挂载。

## 更新插件和桌面程序

在「插件」的更多菜单选择「更新插件」，安装新 ZIP 或填写下载链接。

更新桌面程序时，正常退出 MusicFS，换用完整新版目录，再打开程序。账号、设置和目录保存在用户数据目录中。

想把服务放在云端，参阅 [Worker 部署指南](worker.md)；想接入自己的音乐来源，参阅[插件作者指南](plugin-authoring.md)。
