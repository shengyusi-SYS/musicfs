# 兼容性与验证范围

[English](en/verification.md)

这里汇总已有代表性验证，帮助选择运行方式。日常回归与复测入口见[验证参考](development-reference.md)。

## 平台

| 运行方式 | 已有验证 | 使用条件或未覆盖范围 |
|---|---|---|
| Windows x64 App | 托盘、管理登录、自启注册、后台自动挂载、挂载改名及文件读取 | App 挂载需要 WinFsp，包内提供安装引导；普通用户 UAC 点击未完整验证 |
| Linux / WSL | 正式程序启动、HTTP、rclone/FUSE 挂载与范围读取 | 需要系统 FUSE；原生 Linux 图形托盘仍需实机验证 |
| macOS | 提供构建入口，早期交叉编译检查 | 原生运行、挂载和图形入口尚未验收 |
| Cloudflare Worker | Wrangler 首次部署、管理登录、插件变更、核心升级和有限真实来源读取 | 真实结果来自付费账号；免费 CPU、大目录资源与官方一键部署控制台表单尚未完整验证 |
| Windows 原生 WebDAV 映射 | 本机 HTTPS 映射、64MiB 读取和系统原值恢复 | 系统单文件上限与 WinFsp 挂载不同，处理方式见[桌面指南](desktop.md) |

## 来源与音乐资料

网易云、QQ 示例均验证过真实扫码、保存会话和有限内容读取。账号登录渠道、可见内容、音质及播放权限由来源平台决定；真实账号的自然续期窗口仍未验。

| 格式 | 补标签实现与已有证据 | 范围 |
|---|---|---|
| MP3 | 两示例的真实歌曲、小样本标签解析、完整与范围读取 | 基础资料、封面和歌词；具体字段取决于来源 |
| FLAC | 合成样本标签、区段读取及 Windows / WSL 按需挂载 | 未覆盖所有真实来源曲目 |
| M4A | 普通前置/后置 `moov`、本地 Worker/DAV 和 Windows / WSL 按需挂载 | 分片 MP4 等特殊布局不支持 |
| APE | 工具结构夹具、官方小样本与 WSL 读取试验 | QQ 真实 APE 和 Windows 按需挂载未验；网易云示例不输出 APE |

网易云 MP3、FLAC、M4A 以准确预留表示支持目录先可见、单曲首次读取时补标签。导出文件包含预留填充，大小通常比原文件增加 1MiB；超出预算的资料需刷新后取得新的准确表示。QQ 仍按分页准备。详细合同见[音频标签设计](architecture/audio-tags.md)和[格式工具](../packages/audio-tags/README.md)。

来源已有的歌词时间轴、译文和罗马音会保留。字段写入文件与播放器显示是两个环节，是否展示同步歌词等内容取决于播放器支持。

## 客户端与缓存

rclone/WinFsp、WSL/FUSE、OpenList 和 mpv 有代表性读取或播放验证，覆盖目录、HEAD、单范围读取和定位。不同播放器的整库刮削、歌词界面和离线缓存行为需要按具体客户端确认。

App 本机挂载与直接 WebDAV 各有已读字节缓存；Worker 保持来源流式读取。首次读取尚未缓存的音频仍需连接来源，挂载盘不等同于完整离线音乐库。目录刷新性能不等于播放器扫描耗时。
