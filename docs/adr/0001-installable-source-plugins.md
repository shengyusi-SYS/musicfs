# 将音乐来源适配交给可安装插件

MusicFS 从固定集成网易云与 QQ 调整为可扩展的数据源宿主，用户通过 WebUI 安装、更新和移除插件，无需自行重新编译；这样新增来源不要求修改核心。网易云与 QQ 作为完整可用的示例插件，仅通过公开插件接口接入，其专属规则不进入核心；音质等来源相关配置由插件定义，按数据源实例独立保存，不作为全局配置。同一插件可配置多个独立的数据源实例。

插件向核心提供可浏览内容入口、目录和音频文件，并负责来源专属的版本选择、回退、隐藏、去重、真实元数据及音频范围取流。核心提供目录布局、合法路径、快照、DAV/HTTP 与挂载，以及实例管理、持久化设施和声明式配置/认证界面；核心不要求所有来源具有歌单、扫码或音质概念。

第三方插件可声明支持桌面、Worker 或两者，示例插件仍要求双宿主验收。用户可上传预构建插件包或通过发布地址安装并主动更新；移除保留实例配置与布局引用，标记缺失并停止读取，重新安装兼容插件后可恢复，彻底删除实例数据是单独操作。

这是 2026-10-18 已确认的领域边界，取代原方案固定双平台与每个平台单账号的限制。2026-10-20 已接受 Worker 插件变更时后台自动部署的优先验证路线，见 [ADR 0002](0002-worker-plugin-installation-by-deployment.md)；免费兼容与执行机制仍未验证。过程见 [需求澄清记录](../../outputs/musicfs-design-review.md)。
