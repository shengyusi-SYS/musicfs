# 连接播放器与音乐库

[English](en/clients.md)

先在 MusicFS 的「音乐库」添加来源并完成登录，再按播放器支持的连接方式选择：

| 使用方式 | 怎么连接 |
|---|---|
| 只支持本地路径的播放器、音乐库扫描工具 | 在 MusicFS 添加磁盘挂载，再把盘符或文件夹加入播放器 |
| 支持 WebDAV 的播放器 | 在「连接与挂载 → WebDAV 播放器」复制连接信息或扫码导入 |
| OpenList | 添加 WebDAV 存储，由 OpenList 代理读取 |
| 下载、复制后离线使用 | 从挂载目录复制文件，或用 WebDAV 客户端下载 |

## 挂载为本地磁盘

在「连接与挂载 → 磁盘挂载」添加挂载。Windows 可留空自动分配盘符，首次按页面提示安装 WinFsp；Linux 使用空目录并准备 FUSE。挂载完成后，把该路径加入播放器或扫描工具。

挂载发生在运行 MusicFS 后台的机器上。需要 Windows 盘符时运行 Windows 版；用 Windows 浏览器管理 NAS 或 WSL，不会在 Windows 上产生盘符。也可以在自己的电脑运行 MusicFS，挂载远程 WebDAV。

资源管理器原生映射是另一种连接方式，使用 App 提供的本机 HTTPS 和连接设置，具体见[桌面指南](desktop.md#windows-资源管理器原生映射)。日常使用从 App 的磁盘挂载开始即可。

## WebDAV 播放器

1. 打开「连接与挂载 → WebDAV 播放器」。
2. 将完整地址、用户名和密码填入播放器，或点「扫码导入」。二维码包含读取账号和密码，适用于支持该地址格式的播放器。
3. 播放器在另一台设备上时，把 WebDAV 访问设为「局域网设备」，选择它能连接的地址。管理页面可继续设为「仅本机」。

播放器使用这里的读取凭据；MusicFS 管理账号和音乐平台账号分别用于各自登录。更改读取凭据后，在已有播放器中同步修改。

另一台电脑、容器或 NAS 内的 `127.0.0.1` 指向它自己，应填写该环境能访问的 MusicFS 地址。Worker 使用部署后的 HTTPS 域名和 `/dav/` 路径。

## OpenList

在 OpenList 的「管理 → 存储 → 添加」选择 **WebDAV**：

| 字段 | 填写内容 |
|---|---|
| 挂载路径 | 自选，例如 `/音乐` |
| 地址 | MusicFS 显示的完整 WebDAV 地址 |
| 用户名、密码 | MusicFS 的读取凭据 |
| 根文件夹路径 | `/`，或要连接的子目录 |
| 供应商 | 其他 |
| 网页代理 | 开启 |
| WebDAV 策略 | 本机代理 |

保存后即可浏览、播放和下载。代理由 OpenList 保存读取凭据并转发音频。[OpenList WebDAV 文档](https://doc.oplist.org/guide/drivers/webdav)

## 扫描、刮削与离线文件

来源目录按需加载。网易云示例的 MP3、FLAC、M4A 清单加载完成后即可连接，标签在首次读取歌曲时补齐；其他来源或格式可能先显示「准备文件」，完成后再扫描即可。扫描器逐首读取标签时，首次仍需逐首取得尚未准备的资料。

扫描器可读取音频中已有的歌名、歌手、专辑、封面和歌词。播放器是否显示同步歌词、译文或多位歌手取决于它自身支持。自定义文件名在来源或目录的「设置 → 文件命名」中预览并应用。

挂载目录是只读的。需要让刮削工具改写标签、生成自己的封面或重命名文件时，先复制或下载到本地目录，再交给工具整理。

已读片段缓存帮助重复读取；离线使用应下载完整文件，而不是只保留挂载路径。各类缓存的调整见[使用指南](user-guide.md#更新歌单和管理缓存)。

## 内容没有更新或首次打开等待

先在 MusicFS 选中来源或目录点「更新」，再刷新播放器或 OpenList 的目录缓存。OpenList 使用页面工具栏中的「刷新」，仅重载浏览器可能仍显示其缓存。

首次准备时，部分客户端会显示暂时不可用。回到 MusicFS 查看更新或准备进度，完成后刷新客户端目录或重试扫描；已有内容在后台更新时继续可读。
